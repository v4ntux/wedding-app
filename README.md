# nvate — Wedding Atelier

Студия свадебных приглашений с пятью реалистичными дизайнами: Royal, Atlas, Bahor, Oqshom и Marsala. Стекло, золотые детали, предметные текстуры и медленное раскрытие конверта. План и визуальная система: [REDESIGN_PLAN.md](REDESIGN_PLAN.md).

## Возможности

- Коллекция сразу на первом экране: фильтры светлых/тёмных дизайнов, полный просмотр и выбор.
- Четыре шага редактора: событие → фото и музыка → гости → контакты и проверка.
- RU/UZ, светлая и тёмная тема, клавиатурное управление, системное уменьшение анимации.
- Локальный черновик, включая перенос черновиков старой студии. Черновик хранится только на этом устройстве.
- Имена, дата, время, место, поиск на карте и координаты; загрузка до 6 фото (минимум зависит от шаблона).
- Загрузка аудио, YouTube/прямая аудиоссылка или поиск в каталоге. Каталог возвращает 30-секундные фрагменты iTunes, не полные записи.
- Полный предпросмотр с актуальными фото и музыкой. Боковой экран показывает композицию и данные события.
- До 100 именных ссылок; стоимость рассчитывает сервер, действующие цены сохранены.
- Отсчёт и скачивание события для календаря используют время Узбекистана (UTC+05:00).
- Заявка сохраняется в SQLite. Администратор подтверждает оплату в Telegram, затем появляются общая и именные ссылки.

## Локальный запуск

Нужен Node.js 22.5+ (встроенный node:sqlite). Установка: npm ci.

Для разработки без Telegram в PowerShell:

    $env:DEV_NO_AUTH='1'
    npm run dev

Откройте http://localhost:3000/app/. Этот режим предназначен только для локальной разработки.

Для Telegram/production скопируйте .env.example в .env, задайте BOT_TOKEN, BOT_USERNAME, ADMIN_CHAT_IDS и HTTPS BASE_URL. DEV_NO_AUTH должен оставаться 0. Запуск: npm start. Токены и пользовательская база в Git не сохраняются.

## Проверка

    npm run check
    npm test

Тесты используют отдельную временную SQLite-базу, подписанные тестовые Telegram-данные и локальный HTTP-сервер. Они проверяют все пять шаблонов на RU/UZ, экранирование текста, дату/часовой пояс, защиту API, загрузку, свежесть предпросмотра, серверную цену, подтверждение оплаты и именные URL. Реальные заявки и уведомления не создаются.

## Структура

- public/app/index.html, style.css — студия и адаптивная визуальная система.
- public/app/app.js — коллекция, язык, тема, просмотр и список заявок.
- public/app/studio.js — редактор, черновики, фото, музыка и отправка.
- templates/<id>/ — пять отдельных композиций и их manifests. ID сохранены для существующих заявок.
- src/luxuryBlocks.js — общие безопасно экранированные блоки открытки.
- public/app/invitation.css, invitation.js — темы, движение и календарь.
- src/render.js, templateStore.js — данные и загрузка шаблонов.
- src/server.js, service.js, db.js, bot.js — существующая платформа Node/Express/SQLite/Telegram.
- public/app/assets/source-manifest.json — точные промпты трёх оригинальных фонов (built-in image_gen). Финальные WebP расположены рядом, суммарно около 427 КБ.

## Развёртывание

Приложению нужен Node.js-хост с постоянным диском для data/ и HTTPS reverse proxy. SQLite, файловые загрузки и Telegram long polling требуют работающего Node-процесса. Эта версия не переносит backend на Cloudflare Workers; публикация в Sites без такого переноса не поддерживается. Резервируйте data/ и не включайте DEV_NO_AUTH на публичном сервере.
