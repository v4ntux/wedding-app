# Каталог тойхон

`venues.json` — стартовый список мест, который платформа показывает на шаге
«Где» вместо пустой карты. В Мангите тойхоны не размечены ни в Яндексе, ни в
Google, поэтому справочник мы ведём сами.

## Как это работает

1. `venues.json` — семя, которое едет в git вместе с кодом.
2. Всё, что админ меняет в панели, ложится в таблицу `settings` (ключ `venues`)
   и **перекрывает** семя целиком. Файл после этого можно не трогать.
3. Форма запрашивает список у `GET /api/venues` и рисует по нему точки на карте
   и карточки под ней.

## Поля

| поле      | что это                                              |
|-----------|------------------------------------------------------|
| `id`      | латиницей, без пробелов — попадает в ссылки и логи    |
| `name`    | название как на вывеске                               |
| `kind`    | `toyxona` · `restoran` · `kafe` · `bog`               |
| `address` | ориентир: улица, рядом с чем                          |
| `lat/lng` | точка на карте                                        |
| `seats`   | сколько мест (0 — не знаем)                           |
| `phone`   | телефон администратора, необязательно                 |
| `draft`   | `true` — черновик: виден только в админке              |

## Черновики

Записи в семени помечены `"draft": true`: **парам они не показываются**.
Это заготовки — откройте админку → «Тойхоналар», проверьте название,
поставьте точку и снимите галочку «Черновик». Только после этого место
появится на карте у пар.

Пока каталог пуст (или весь в черновиках), шаг «Где» работает как раньше:
поиск по геокодеру и точка пальцем по карте.
