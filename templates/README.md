# Шаблоны приглашений

Каждый шаблон — папка: `templates/<id>/manifest.json` + `templates/<id>/template.html`.
Сервер подхватывает папку на лету (fs.watch); сломанный шаблон пропускается с ошибкой
в логе и не роняет остальные.

**Под новый id в коде нужно одно место, ещё два — по желанию:**

- `STATIONERY` в `src/design.js` — цвета обложки в витрине студии и описание темы.
  Без записи `buildData()` падает на `stationery.paper`, и шаблон отдаёт 500.
- `ENVELOPES` в `src/experience.js` — бумага, подкладка и сургуч конверта (только если тема
  открывается классическим конвертом). Без записи конверт берёт общий коричневый DEFAULT_ENVELOPE.
- Обложка витрины `public/app/covers/<id>.webp` — кадр самой темы
  (`node scripts/render-covers.mjs`). Без неё студия рисует карточку из цветов `STATIONERY`.

## manifest.json

```json
{
  "name": "Marsala",              // имя в каталоге и форме
  "event": "wedding",             // wedding | birthday | anniversary (см. EVENTS в src/templateStore.js)
  "price": 129000,                // цена в сумах
  "minPhotos": 1,                 // минимум фото для этого дизайна
  "colors": ["#5C2233", "#F4EFE4"], // палитра карточки в форме (до 4)
  "order": 1,                     // порядок в каталоге (меньше = выше)
  "listed": true,                 // false = legacy: рендерится по старым ссылкам, скрыт из каталога
  "strings": {                    // (необязательно) переопределение текстов LOCALES
    "uz": { "invite": "..." },
    "ru": { "until": "До юбилея осталось" }
  }
}
```

## template.html

Обычный HTML со вставками:

- `{{x}}` — значение с экранированием: `{{groom}}`, `{{bride}}`, `{{groomInitial}}`, `{{brideInitial}}`,
  `{{dateText}}`, `{{day}}`, `{{monthName}}`, `{{year}}`, `{{weekday}}`, `{{time}}`, `{{targetIso}}`,
  `{{address}}`, `{{guestName}}`, `{{lang}}`, строки локали `{{L.sub}}`, `{{L.invite}}`, `{{L.openHint}}` и т.д.
- `{{{x}}}` — готовые блоки движка (вставлять как есть):
  `{{{experienceCSS}}}` (в `<head>`, до своего CSS), `{{{experienceScript}}}`, `{{{audioWidget}}}`,
  `{{{map}}}`, `{{{countdown}}}`, `{{{grain}}}` (текстура для CSS `background-image`).
- Условия и циклы: `{{#if guestName}}...{{else}}...{{/if}}`, `{{#if photos.0}}...{{/if}}`,
  `{{#each photos}}<img src="{{this}}">{{/each}}`.

## Обязательная разметка

1. **Открытие** — сцена с атрибутом `data-envelope-scene` и кнопкой `data-envelope-trigger` внутри. Два пути:
   - классический конверт: `{{{envelope}}}` первым элементом `<body>` — движок (`src/experience.js`) сам нарисует конверт в цветах темы (`ENVELOPES`);
   - своя сцена (так открываются все темы линейки 2026): своя разметка и CSS, а партитуру задают атрибуты сцены — `data-leave` (мс до класса `is-leaving` и `body.ev-handoff`), `data-done` (мс до скрытия сцены и старта страницы), `data-music` (когда вступает песня), `data-sfx="0"` (без шелеста бумаги). По касанию сцена получает класс `is-running`; документ получает события `nv:open`, `nv:leave` и `nv:ready` (в режиме карточки витрины — `nv:ready` с `detail.card`).
   Старые `.envx`/`#env` продолжают работать для legacy-шаблонов.
   Не анимируйте `opacity` у элемента с `transform-style:preserve-3d`: прозрачность сплющивает его, и вместо оборота гость видит зеркальную лицевую сторону. Гасите обёртку.
2. **Отсчёт** — элементы с `id="cd" ch cm cs"` внутри секции отсчёта + `{{{countdown}}}` перед `</body>`.
3. **Появление при скролле** — класс `fx` на секциях (задержка через `style="--d:.2s"`).
   **Скролл-сцены** — атрибут `data-scrub` даёт элементу `--p` от 0 до 1: `view` (по умолчанию) — пока блок проходит экран, `enter` — пока въезжает, `sticky` — за прокрутку высокой обёртки со sticky-сценой внутри. Дальше всё одним CSS: `transform:rotateY(calc(var(--p) * -180deg))`, `clip-path:circle(calc(var(--p) * 90%))`… При `prefers-reduced-motion` движок ставит `--p:1`, поэтому финальное состояние сцены должно быть читаемым.
4. **Страница прокручивается до конца.** Студия засчитывает просмотр предпросмотра, когда гость долистал до низа, поэтому даже «книга» листается прокруткой, а не горизонтальными слайдами.
5. **Подписи отсчёта** — селектором `.cd>div>span`, а не `.cd span`: внутри цифр движок вставляет свои `span` (барабан), и правило для подписи уменьшило бы цифры.
6. Порядок в конце `<body>`: `{{{audioWidget}}}` → `{{{experienceScript}}}` → `{{{countdown}}}`.

## Общие узлы оформления (`src/theme.js`)

- **Фото** — `<figure class="shot" data-fit><img …></figure>`. С `data-fit` рамка берёт пропорцию
  самого снимка (от 3:4 до 3:2); без него — `aspect-ratio` темы, лучше через `var(--ratio,3/4)`.
  Текста поверх фотографии нет: подпись, если нужна, ставится под рамкой. Кромка кадра — `--shot-edge`.
- **Секции** прозрачные. Вуаль под текстом задаёт тема одной переменной `.inv{--veil:rgba(…)}`,
  своих заливок на `.sec` не ставить — на стыках появятся полосы.
- **Место** — карта сверху во всю ширину карточки, под ней `.venue__body` с адресом и `.routes`
  (две равные кнопки, подпись в `<span>`, стрелка — `<svg>`).
- **Надзаголовки** `.num` — просто слово («Qachon»), без номеров.
- Светлой теме нужен `--glass-face-solid`: на телефоне стекло без размытия берёт эту заливку.
